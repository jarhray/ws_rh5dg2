# 离线验证

在工作区构建后运行：

```bash
./scripts/test.sh
```

脚本加载系统 Humble 和本工作区，先执行 `colcon test` / `colcon test-result`，通过后执行串口 ROS 集成验收。传入参数仅传给 `colcon test`；集成验收始终完整运行。

只运行集成验收：

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
PYTHONNOUSERSITE=1 /usr/bin/python3 tests/run_integration.py
```

测试内部创建两个 `/dev/pts/*` 虚拟串口、协议应答线程和驱动进程，在独立 localhost ROS domain 中运行。不接受外部串口路径，不连接实机或用户运行的驱动；应答器只供测试，不安装为运行后端。

主要覆盖：

- 协议帧校验、设备打不开或串口被占用时启动失败。
- 默认接收 topic、可选只读启动和显式使能、五种服务/topic 控制及双手命名空间隔离。
- 文档范围内的角度上下端点、越界截断、负侧摆、`-1` 跳过，以及返回实际下发值和限幅标记。
- 左手角度整组 ACK=32、单字/停止 ACK=2，右手 ACK=1；非标准应答须精确读回，未知 ACK 或读回失败被拒绝。
- 部分角度只写指定通道，完整数组整组写入；中途失败停止余下写入。
- 通信故障撤销使能并使反馈失效，保留最后值与采集时间；重连不重放目标。
- 反馈有效性、单位、通道掩码和 24 位触觉接近值；命令时间戳与模式配对检查。
- 使能/禁用、示例退出及驱动退出均不写急停；只有显式急停/解除急停操作会修改 1301。
- 仅提供 topic 订阅者、不提供任何服务时，示例仍只发布一次；目标不可达也不等待、不重试、不写急停。
- 连续启动 topic 示例进程，确认限幅后的目标到达串口；测试限位从当前配置读取。
- launch 继承 YAML 配置、显式参数覆盖、两侧串口路径/别名重复检查。

集成测试结束或失败会清理子进程及串口。日志保存在 `log/integration/<run>/serial_test.log`，失败时包含驱动输出。ROS 集成需要本机 DDS 通信权限。

这些测试不验证真实机械端点、力/速度标定或设备延迟。历史测试与实机记录见 [VALIDATION.md](VALIDATION.md)。
